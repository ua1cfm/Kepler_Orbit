# Kepler Orbit

**Kepler Orbit 0.2.05** — Android-приложение для расчёта положения искусственных спутников Земли, прогноза пролётов и управления антенным поворотным устройством по протоколу **Yaesu GS-232B**.

Приложение объединяет спутниковый трекер, расчёт орбиты по TLE/SGP4, расписание пролётов, радиолюбительский интерфейс наблюдения и управление повороткой через **USB-OTG**, **Wi‑Fi/TCP** или **Bluetooth Classic SPP/RFCOMM**.

Текущая версия проекта: **0.2.05**  
Android package: `ua1cfm.keplertutor`  
Автор проекта: **UA1CFM**

---

## Основные возможности

### Спутниковый трекер

- загрузка и разбор TLE;
- расчёт положения спутника по модели SGP4;
- отображение текущих:
  - азимута;
  - угла места;
  - координат подспутниковой точки;
  - параметров выбранного спутника;
- работа с несколькими выбранными спутниками;
- сохранение TLE и выбранных спутников между запусками;
- контроль возраста TLE-данных;
- расчёт положения относительно пользовательской точки наблюдения QTH.

### Прогноз пролётов

Приложение рассчитывает предстоящие пролёты спутников над заданным QTH.

Для каждого пролёта используются:

- AOS — начало видимости;
- LOS — конец видимости;
- максимальный угол места;
- азимут на AOS/LOS;
- длительность пролёта;
- заданный минимальный угол места.

Расчёт пролётов основан на SGP4. Пересечения заданного минимального угла места уточняются дополнительным расчётом времени.

Если программа запущена во время уже начавшегося пролёта, она может восстановить реальное начало текущего прохода.

### Визуализация

В приложении присутствуют несколько способов отображения движения спутников:

- радарная диаграмма небосвода;
- глобус;
- двумерная карта мира;
- отображение трассы орбиты;
- отображение текущего положения спутника;
- карточки предстоящих пролётов;
- прогресс текущего пролёта.

Поддерживаются различные стили карты, включая встроенные и загружаемые варианты:

- `STANDARD`
- `POLITICAL`
- `POLITICAL COLOR`
- `NASA`
- `CONTROL`
- `ORBITRON`

### Звуковые уведомления

Для спутниковых пролётов предусмотрены звуковые сигналы:

- начало пролёта / AOS;
- окончание пролёта / LOS.

Звуковые сигналы формируются непосредственно приложением через Android AudioTrack.

# Управление поворотным устройством

Kepler Orbit поддерживает управление поворотками, совместимыми с **Yaesu GS-232B**.

Поддерживаются три независимых транспорта:

1. **USB / USB-OTG**
2. **Wi‑Fi / TCP**
3. **Bluetooth Classic / SPP / RFCOMM**

В интерфейсе ROTATOR можно переключать используемый тип соединения.

---

## Поддерживаемые команды GS-232B

В проекте используются основные команды:

```text
C2          запрос текущих AZ/EL
Waaa eee    установить AZ/EL
S           STOP
P36         режим азимута 360°
P45         режим азимута 450°
```

Пример команды:

```text
W123 045
```

Пример ответа на `C2`:

```text
AZ=123 EL=045
```

Также поддерживается компактный формат:

```text
+0123+0045
```

# Автоматическое слежение

Приложение может автоматически передавать рассчитанные координаты на контроллер поворотки.

Доступны параметры:

- **Calc, ms** — период пересчёта положения;
- **Step, °** — минимальное изменение угла для отправки новой команды;
- **Min EL, °** — минимальный угол места, ниже которого сопровождение прекращается.

Новая команда `W` передаётся только тогда, когда изменение угла достигает установленного порога.

Порог применяется к азимуту и углу места, чтобы не отправлять лишние команды при каждом небольшом изменении координат.

Первая команда после запуска автоматического сопровождения передаётся сразу.

При уходе спутника ниже `Min EL` отправляется команда:

```text
S
```

После следующего появления спутника выше заданного минимального угла новая координата снова передаётся немедленно.

Для азимута предусмотрена корректная обработка переходов через север и режимов **360° / 450°**.

# USB / USB-OTG

Телефон может напрямую управлять GS-232B-контроллером через USB-OTG.

Поддерживаются типовые Android USB Serial устройства:

- CDC-ACM;
- FTDI;
- CP210x;
- PL2303;
- CH340 / CH341.

Используется библиотека:

```text
usb-serial-for-android 3.9.0
```

Типовые параметры последовательного порта:

```text
9600 baud
8 data bits
No parity
1 stop bit
```

То есть **9600 8N1**.

### Вариант подключения

```text
Android
   |
USB-OTG
   |
USB контроллера
   |
GS-232B
   |
Yaesu G-5500
```

Если контроллер имеет настоящий интерфейс RS-232/DB9, необходим USB-to-RS232 адаптер. Обычный USB-to-TTL UART не заменяет преобразователь уровней RS-232.

# Wi‑Fi / TCP

Kepler Orbit поддерживает управление GS-232B по TCP-соединению.

Этот режим предназначен, в частности, для ESP32-контроллеров поворотки, предоставляющих GS-232B через TCP.

В текущем проекте используется порт:

```text
4533
```

Начиная с версии **0.2.04** приложение использует обычный Android TCP `Socket()` без принудительной привязки сокета к конкретной Wi‑Fi Network.

Это улучшает совместимость с Android VPN.

Если используемый VPN-клиент имеет настройку вида:

```text
Allow LAN
Local network access
Bypass VPN for local network
```

доступ к локальной сети должен быть разрешён.

---

# Bluetooth Classic — HC-05 / HC-06

Начиная с ветки 0.1.92 приложение поддерживает **Bluetooth Classic BR/EDR** с профилем **SPP/RFCOMM**.

Для контроллера на ESP32-S3 удобно использовать внешний модуль **HC-05**.

### Сопряжение

Сначала HC-05 необходимо сопрячь с телефоном в системных настройках Android.

Часто используемые PIN-коды HC-05:

```text
1234
0000
```

Конкретный PIN зависит от прошивки модуля.

После сопряжения:

1. открыть экран `ROTATOR`;
2. выбрать `Bluetooth`;
3. разрешить доступ к Bluetooth-устройствам;
4. нажать `REFRESH`;
5. выбрать сопряжённый HC-05;
6. нажать `CONNECT`;
7. проверить связь кнопкой `READ C2`.

## Android 12+ и Bluetooth permissions

Версия **0.2.05** исправляет подключение HC-05 на современных версиях Android.

На Android 12+ приложение запрашивает:

```text
android.permission.BLUETOOTH_CONNECT
android.permission.BLUETOOTH_SCAN
```

Для `BLUETOOTH_SCAN` используется:

```xml
android:usesPermissionFlags="neverForLocation"
```

Исправлена ситуация, когда подключение к HC-05 завершалось ошибкой:

```text
Need android.permission.BLUETOOTH_SCAN permission
BluetoothAdapterServiceBinder.cancelDiscovery()
```

Теперь `cancelDiscovery()` вызывается только при наличии соответствующего разрешения. Уже сопряжённый HC-05 остаётся доступным для подключения.

# Подключение HC-05 к ESP32-S3 контроллеру

Для контроллера G-5500 на ESP32-S3 модуль HC-05 используется как внешний Bluetooth Classic UART.

Актуальная схема соединения контроллера:

```text
HC-05                  ESP32-S3
--------------------------------
STATE  ------------->  GPIO3
TXD    ------------->  GPIO6  (RX)
RXD    <-------------  GPIO7  (TX)
GND    -------------   GND_SYS
EN/KEY -------------   NC
```

UART:

```text
9600 baud
8N1
```

Модуль передаёт через Bluetooth те же GS-232B команды, что USB и TCP.

> ESP32-S3 не поддерживает Bluetooth Classic SPP встроенными средствами, поэтому для Classic Bluetooth используется внешний HC-05.

# Фоновая работа

В проекте реализован отдельный Android foreground service для управления повороткой.

Используются:

- `FOREGROUND_SERVICE`;
- `FOREGROUND_SERVICE_CONNECTED_DEVICE`;
- `WAKE_LOCK`.

Это позволяет сохранять работу соединения и управление повороткой при свёрнутом приложении и во время длительного сопровождения.

В проекте также присутствуют механизмы повторного подключения и контроля связи с повороткой.

# Yaesu G-5500

При использовании собственного контроллера G-5500 полезны следующие линии внешнего управления:

```text
pin 1 — Elevation feedback
pin 6 — Azimuth feedback
pin 2 — RIGHT / CW
pin 4 — LEFT / CCW
pin 3 — UP
pin 5 — DOWN
pin 8 — COMMON / GND
```

Не подключайте GPIO микроконтроллера непосредственно к управляющим линиям Yaesu G-5500. Используйте оптопары, реле или соответствующие электронные ключи.

Перед включением автоматического сопровождения рекомендуется проверить:

1. чтение координат через `C2`;
2. STOP командой `S`;
3. небольшой ручной поворот командой `W`;
4. правильность режимов `P36` / `P45`;
5. соответствие фактического положения AZ/EL показаниям приложения.

# Совместимость

Приложение рассчитано на Android **8.0 (API 26)** и новее.

Функциональность конкретного транспорта зависит от оборудования:

- USB — телефон должен поддерживать USB Host / OTG;
- Wi‑Fi — контроллер должен предоставлять совместимый TCP GS-232B интерфейс;
- Bluetooth — требуется устройство Bluetooth Classic SPP, например HC-05/HC-06.

# Важное замечание

Автоматическое управление реальным антенным поворотным устройством связано с механическим движением оборудования.

Перед использованием:

- задайте корректные пределы AZ/EL;
- проверьте калибровку;
- убедитесь в возможности немедленной остановки;
- сначала протестируйте команды на небольшом перемещении;
- следите, чтобы кабели антенн не могли быть повреждены при вращении.
