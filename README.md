# Kepler Orbit Tutor

**Kepler Orbit Tutor** — Android-приложение для работы с орбитальными данными спутников, расчёта пролётов и управления антенным поворотным устройством по протоколу **Yaesu GS-232B**.

Текущая версия: **0.1.56 — Continuous Rotator Feedback**  
Автор: **UA1CFM**

Приложение объединяет в одном интерфейсе загрузку и анализ TLE, визуализацию орбиты, расчёт видимых пролётов, сопровождение спутника и управление ротатором по USB/OTG или Wi‑Fi/TCP.

---

## Основные возможности

### TLE и орбитальные данные

- открытие локальных TLE-файлов;
- поддержка стандартных 2-line и 3-line TLE-наборов;
- загрузка актуального `satonline.txt` из источников R4UAB;
- резервный источник SATGS;
- автоматическое сохранение последнего TLE;
- восстановление сохранённого TLE после перезапуска приложения;
- удаление сохранённого TLE из интерфейса;
- сохранение выбранных спутников;
- отображение возраста TLE;
- под именем загруженного файла показывается время, прошедшее с момента самых свежих данных TLE;
- отображение исходных элементов TLE и рассчитанных орбитальных параметров.

Орбитальные расчёты выполняются с использованием библиотеки **Predict4Java / SGP4**.

---

## ORBIT / MAP

Страница предназначена для просмотра текущего положения выбранного спутника и его орбиты.

Возможности:

- текущие азимут и элевация;
- положение спутника относительно наблюдателя;
- 3D-глобус;
- отображение орбиты вокруг Земли;
- 2D-карта;
- траектория спутника на карте;
- корректная обработка перехода линии орбиты через ±180° долготы;
- сохранение полной орбиты после изменения QTH;
- ввод координат наблюдателя;
- работа с QTH Locator;
- преобразование координат в Locator;
- применение местоположения пользователя;
- отображение параметров выбранного спутника.

---

## PASSES

Расчёт расписания пролётов выбранных спутников над точкой наблюдения.

Поддерживается:

- одновременный выбор нескольких спутников;
- сохранение выбора между запусками приложения;
- расчёт пролётов на заданный интервал времени;
- настройка минимальной элевации;
- список пролётов;
- время начала и окончания пролёта;
- максимальная элевация;
- длительность пролёта;
- обратный отсчёт до начала пролёта или до его окончания;
- карточки пролётов;
- переход из карточки пролёта к экрану сопровождения.

Интерфейс рассчитан на работу на телефонах с разным размером и плотностью экрана.

---

## ROTATOR

Приложение умеет напрямую управлять совместимым GS-232B-контроллером поворотного устройства.

### Подключение

Доступны два варианта:

**USB / OTG**
- Android USB Host;
- USB-Serial;
- работа с совместимыми USB-UART адаптерами и контроллерами.

**Wi‑Fi / TCP**
- подключение к GS-232B / Hamlib-совместимому контроллеру по сети;
- стандартный порт проекта контроллера G-5500: `4533`.

---

## Поддерживаемые команды ротатора

В интерфейсе используются команды GS-232B, в том числе:

```text
C2          Read AZ + EL
Waaa eee    Set AZ + EL
S           Stop
P36         360° azimuth mode
P45         450° azimuth mode
```

Поддерживается ручная отправка координат для проверки работы контроллера.

---

## AUTO TRACK

Автоматическое сопровождение рассчитывает текущее положение выбранного спутника и передаёт новые целевые координаты ротатору.

Особенности:

- выбор шага обновления цели;
- варианты шага: `1°`, `3°`, `5°`, `7°`, `10°`;
- порог изменения применяется к координатам ротатора;
- режимы азимута 360° и 450°;
- минимальная рабочая элевация;
- управление частотой обновления;
- STOP;
- отображение расчётной позиции спутника;
- отображение фактического положения ротатора.

---

## ROTATOR FEEDBACK

Строка **ROTATOR FEEDBACK** показывает реальные координаты, возвращаемые контроллером.

Начиная с версии **0.1.56**, обратная связь обновляется постоянно, пока контроллер подключён:

- во время AUTO TRACK;
- во время PARK;
- после ручной команды `Waaa eee`;
- в обычном подключённом состоянии.

Фоновый запрос положения выполняется примерно каждые **500 мс**.

Это позволяет одновременно видеть:

```text
цель приложения → движение ротатора → фактические AZ / EL
```

## Парковка ротатора

Начиная с версии **0.1.55** добавлена парковочная позиция.

Можно задать:

```text
PARK AZ
PARK EL
```

и нажать:

```text
PARK ROTATOR
```

Парковочная позиция сохраняется между запусками приложения.

### PARK AFTER LOS

Дополнительный режим:

```text
PARK AFTER LOS
```

По умолчанию выключен.

Если режим включён, после ухода сопровождаемого спутника ниже геометрического горизонта приложение:

1. отправляет ротатору сохранённую PARK-позицию;
2. завершает AUTO TRACK.

---

## Поддержка 360° / 450°

Для ротаторов и контроллеров, поддерживающих расширенный диапазон азимута, предусмотрены режимы:

```text
P36 • 360°
P45 • 450°
```

Режим учитывается также при проверке допустимого значения PARK AZ.

## Совместимое оборудование

Приложение ориентировано на контроллеры, использующие интерфейс **Yaesu GS-232B**.

В частности, проект разрабатывался совместно с контроллером:

**Yaesu G-5500 Controller on ESP32-S3 / UA1CFM**

Подключение может выполняться:

```text
Android → USB/OTG → GS-232B controller
```

или:

```text
Android → Wi‑Fi/LAN → TCP 4533 → ESP32-S3 controller → Yaesu G-5500
```

## Текущая версия

### 0.1.56 — Continuous Rotator Feedback

Основное изменение:

- обратная связь от ротатора больше не прекращается при PARK или ручной проверке;
- фактические AZ/EL продолжают обновляться каждые ~500 мс при подключённом контроллере;
- PARK и manual `Waaa eee` выполняют дополнительный немедленный запрос положения;
- устранён дублирующий опрос feedback во время AUTO TRACK.

---

## Важное замечание

Перед первым использованием управления ротатором рекомендуется проверить:

- правильность направления AZ;
- правильность направления EL;
- диапазон P36/P45;
- фактическую обратную связь C2;
- PARK-позицию;
- работу STOP.

Первые проверки желательно выполнять на безопасных координатах, контролируя движение антенны визуально.
